# negate test data

`negate` computes `-din` and requantizes to the output format.

Generated by `test_data/scripts/gen_fixed_point_test_data.py` from an exact rational-arithmetic golden model (not exported from MATLAB). Each `simdataN/` holds a `params.json` with the DUT parameters (the testbench uses it to select the data set), input words `sim_din.csv` and expected output words `sim_dout.csv`. All words are raw unsigned bit patterns, one per clock cycle. Expected outputs already include the pipeline latency (the first `CSP_LATENCY` values are the zero power-on state). Sets with `MISC` = 1 also drive random `MISC_WIDTH`-bit words on `sim_misci.csv` and expect them on `sim_misco.csv`, delayed by the casper misc latency; the other sets leave `MISC` at its default 0 (no misc files, not in `params.json`).

The first cycles walk corner-case words (0, 1, all-ones, MSB only, MSB−1, MSB+1; all pairs for 2-input modules), and the rest are seeded uniform-random words.

Encodings: `TYPE` 0=unsigned, 1=signed; `QUANTIZATION` 0=truncate, 1=round half away from zero, 2=round half to even; `OVERFLOW` 0=wrap, 1=saturate.
