# scale test data

`scale` computes `din · 2^SCALE_FACTOR` and requantizes to the output format.

Generated by `test_data/scripts/gen_fixed_point_test_data.py` from an exact rational-arithmetic golden model (not exported from MATLAB). Each `simdataN/` holds a `params.json` with the DUT parameters (the testbench uses it to select the data set), input words `sim_din.csv` and expected output words `sim_dout.csv`. All words are raw unsigned bit patterns, one per clock cycle. Expected outputs already include the pipeline latency (the first `LATENCY` values are the zero power-on state). Sets with `MISC` = 1 also drive random `MISC_WIDTH`-bit words on `sim_misci.csv` and expect them on `sim_misco.csv`, delayed by the casper misc latency; the other sets leave `MISC` at its default 0 (no misc files, not in `params.json`).

The first cycles walk corner-case words (0, 1, all-ones, MSB only, MSB−1, MSB+1; all pairs for 2-input modules), and the rest are seeded uniform-random words.

Encodings: `TYPE` 0=unsigned, 1=signed; `QUANTIZATION` 0=truncate, 1=round half away from zero, 2=round half to even; `OVERFLOW` 0=wrap, 1=saturate.

**CSV data exported from the corresponding MATLAB Simulink block.**

Simulink data: the `sim_*.csv` files of sets 0–5 were exported from Simulink models of the block (MATLAB R2021a, System Generator; plugins-demo2 export flow with its own random stimulus) and copied here on 2026-10-14; `params.json` (and any `.mem` files) are the generator's. Regenerating the module with its script replaces the exported CSVs with the reference model's output.
