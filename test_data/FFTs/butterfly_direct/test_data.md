# butterfly_direct test data

`butterfly_direct` computes `a + b·w` and `a − b·w` through the twiddle variant that casper's selection rule picks for `Coeffs` (column *Twiddle*), then shifts (dynamic `shift` input, hardcoded `DOWNSHIFT`, or bit growth), requantizes to `BIN_PT_IN` and flags overflow per lane. `sync_in` pulses once per coefficient frame (plus one early re-sync); `shift` toggles every 8–39 cycles. Cycles 1–4 drive the extreme words on every lane, the rest are seeded random.

Generated by `test_data/scripts/gen_butterfly_test_data.py`: a Python reference model of `butterfly_direct_init.m` on top of the twiddle reference models of `test_data/scripts/gen_twiddle_test_data.py` (not exported from MATLAB). `params.json` also records casper's `COEFFS`; `twiddle.mem` (twiddle_general only) comes from `rtl/FFTs/Twiddle/scripts/gen_twiddle_coeffs.py`. CSV rows are cycles, lane ports have `N_INPUTS` columns (lane 0 first), `sim_of.csv` holds the `of` bus as an integer (bit n = lane n); all values are raw unsigned bit patterns with the pre-edge read convention.
