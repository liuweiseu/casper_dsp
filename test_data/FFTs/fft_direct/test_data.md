# fft_direct test data

`fft_direct` is a fully parallel FFT of 2^FFT_SIZE samples per stream per cycle, built from butterfly_direct stages as `fft_direct_init.m` wires them. `sync` pulses every 16 cycles (MAP_TAIL off) or every 2^(LARGER_FFT_SIZE−FFT_SIZE) cycles, the coefficient period (MAP_TAIL on). Data are random: small (1/8 of full scale) for the sets with an FFT check, full scale otherwise (so the overflow flags are exercised); `shift` is all ones or random per cycle. *FFT check*: numpy check that each cycle's outputs are the FFT of that cycle's inputs, divided by 2^FFT_SIZE (worst error in output LSBs); not applicable to MAP_TAIL (only the tail of a larger FFT) or non-uniform shifts. The twiddle tables come from `rtl/FFTs/scripts/gen_fft_mem_files.py direct`; `COEFF_DIR` is relative to `tests/sim_build/FFTs/fft_direct/`.

Generated by `test_data/scripts/gen_fft_wideband_test_data.py` (reference models, not exported from MATLAB). CSV rows are cycles; array ports have one file per element (`sim_<port><j>.csv` = element j).
