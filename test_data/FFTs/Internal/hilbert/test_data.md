# hilbert test data

`hilbert` computes `even = (a + conj(b))/2` and `odd = (a − conj(b))/(2j)` per lane: full-precision sums, then a halving bus_convert with round-half-even and wrap. Row 0 is zero, then corner words, all pairs of corner words on (a, b), then random words; the corners include the one case that wraps (`b_re` maximum, `a_re` most negative). Sets with `MISC` = 1 also drive random `MISC_WIDTH`-bit words on `sim_misci.csv`, expected on `sim_misco.csv` delayed by `ADD_LATENCY + CONV_LATENCY` (`hilbert_init.m`); the other sets leave `MISC` at 0 (not in `params.json`).

Generated by `test_data/scripts/gen_fft_internal_test_data.py` (reference model, not exported from MATLAB). CSV rows are cycles; array ports have one file per lane (`sim_<port><j>.csv` = lane j).
