# mirror_spectrum test data

`mirror_spectrum` passes `din<i>` for frame counts 0 … 2^(FFT_SIZE−1) and outputs `conj(reo_in<i>)` above that (casper Relational a>b). `sync` pulses every 2^FFT_SIZE cycles plus one early re-sync mid-run that restarts the frame counter; data are random words with corner words at the start (so the Wrap of the negate is exercised).

Generated by `test_data/scripts/gen_fft_internal_test_data.py` (reference model, not exported from MATLAB). CSV rows are cycles; array ports have one file per lane (`sim_<port><j>.csv` = lane j).

**CSV data exported from the corresponding MATLAB Simulink block.**

Simulink data: the `sim_*.csv` files of sets 0–2 were exported from Simulink models of the block (MATLAB R2021a, System Generator; plugins-demo2 export flow with its own random stimulus) and copied here on 2026-10-14; `params.json` (and any `.mem` files) are the generator's. Regenerating the module with its script replaces the exported CSVs with the reference model's output.

## Sets exported from MATLAB Simulink

The sets below are the casper `async` mode (`ASYNC = 1`). Each is a set of the table above (or, where noted, a variant of one) with `ASYNC = 1`; `en` is random (about 70 % high, 0 at cycle 0), `sim_en.csv` drives it and `sim_dvalid.csv` is checked. The generator does not write these sets and keeps this section when it rewrites the file.
