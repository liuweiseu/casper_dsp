# complex_conj test data

`complex_conj` delays the real part and negates the imaginary part (bus_negate, Truncate, `OVERFLOW` 0 = Wrap / 1 = Saturate) with latency `LATENCY`. Row 0 is zero, then corner words (0, 1, −1, most negative, …) on every lane, then random words.

Generated by `test_data/scripts/gen_fft_internal_test_data.py` (reference model, not exported from MATLAB). CSV rows are cycles, one column per lane.
