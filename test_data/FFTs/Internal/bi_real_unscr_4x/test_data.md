# bi_real_unscr_4x test data

`bi_real_unscr_4x` turns a biplex FFT of `z1 = pol1 + j·pol2`, `z2 = pol3 + j·pol4` into the full spectra of the four real signals. The inputs are the output of the biplex_core reference model (`gen_biplex_test_data.py`, all stages shifting, no bit growth) for 7 frames of four random real signals, as in fft_biplex_real_4x. The script checks with numpy that every output frame after the first is the FFT of one input frame of each signal, the same number of frames earlier each time (column *FFT frames checked*, worst error in output LSBs). For `FFT_SIZE` = 2 casper's block is not an FFT: the even map is the identity, and an order-1 reorder is one cycle slower than the order-2 odd one (`reorder_init.m` pre_delay), so even and odd are misaligned; the data reproduce that behaviour bit-exactly. `map_even.mem`, `map_odd.mem` and `map_out.mem` come from `rtl/Reorder/scripts/gen_reorder_map.py --bi-real`; `MAP_DIR` is relative to the simulator's working directory `tests/sim_build/FFTs/Internal/bi_real_unscr_4x/`.

Generated by `test_data/scripts/gen_fft_internal_test_data.py` (reference model, not exported from MATLAB). CSV rows are cycles; array ports have one file per lane (`sim_<port><j>.csv` = lane j).

**CSV data exported from the corresponding MATLAB Simulink block.**

Simulink data: the `sim_*.csv` files of sets 0–4 were exported from Simulink models of the block (MATLAB R2021a, System Generator; plugins-demo2 export flow with its own random stimulus) and copied here on 2026-10-14; `params.json` (and any `.mem` files) are the generator's. Regenerating the module with its script replaces the exported CSVs with the reference model's output.

## Sets exported from MATLAB Simulink

The sets below are the casper `async` mode (`ASYNC = 1`). Each is a set of the table above (or, where noted, a variant of one) with `ASYNC = 1`; `en` is random (about 70 % high, 0 at cycle 0), `sim_en.csv` drives it and `sim_dvalid.csv` is checked. The generator does not write these sets and keeps this section when it rewrites the file.
