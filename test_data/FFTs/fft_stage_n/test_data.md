# fft_stage_n test data

`fft_stage_n` is one biplex FFT stage: a commutator (delays `P` and `P+ND`, a sync-reset counter, two muxes) pairs samples `ND = 2^(FFT_SIZE-FFT_STAGE)` apart and feeds them to `butterfly_direct` with casper's stage coefficients. `sync` pulses once per `2^FFT_SIZE`-cycle frame plus one early re-sync; the `shift` bus holds random values for 20–59 cycles at a time; `of_in` has sparse random bits. The derived columns (`P`, `ND`, mux latency, RAM delays) are what `fft_stage_n_init.m` computes for each configuration.

Generated by `scripts/gen_fft_stage_test_data.py`: a Python reference model of `fft_stage_n_init.m` on top of the butterfly reference model of `scripts/gen_butterfly_test_data.py` (not exported from MATLAB). `twiddle.mem` (stages ≥ 3) comes from `scripts/gen_twiddle_coeffs.py`. CSV rows are cycles, lane ports have `N_INPUTS` columns (lane 0 first), bus ports are integers; raw unsigned bit patterns with the pre-edge read convention.
