# biplex_core test data

`biplex_core` chains `FFT_SIZE` `fft_stage_n` stages. `sync` pulses once per `2^FFT_SIZE`-cycle frame plus one early re-sync; the `shift` bus holds random values for 20–79 cycles at a time. Inputs are full-scale random words, so overflow flags and wrap / saturation are exercised too.

Generated by `scripts/gen_biplex_test_data.py`: the `fft_stage_n` reference model of `scripts/gen_fft_stage_test_data.py` chained over the stages, each stage's parameters derived as `biplex_core_init.m` does (recorded under `STAGES` in `params.json`). Not exported from MATLAB. The script also checks, with numpy, that this chained model computes the FFT of each stream in bit-reversed order to within the rounding error. `twiddle_stage<s>.mem` (stages ≥ 3) come from `scripts/gen_twiddle_coeffs.py`; `COEFF_DIR` is relative to the simulator's working directory `tests/sim_build/FFTs/biplex_core/`. CSV rows are cycles, lane ports have `N_INPUTS` columns, bus ports are integers; raw unsigned bit patterns with the pre-edge read convention.
