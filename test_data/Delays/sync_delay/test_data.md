# sync_delay test data

`sync_delay` delays a sync pulse by `DELAY_LEN` cycles with a loadable down counter (a new pulse restarts the count, so pulses closer than `DELAY_LEN` collapse into the last one). Pulses are mostly spaced `DELAY_LEN`…`2·DELAY_LEN+7` cycles apart, plus 4 at random positions to exercise the restart.

Generated by `scripts/gen_fft_stage_test_data.py` (Python reference model of `sync_delay_init.m`, not exported from MATLAB). Files: `sim_din.csv`, expected `sim_out.csv`, one value per cycle.

| Test # | Directory | DELAY_LEN | Cycles | Description |
|---|---|---|---|---|
| 0 | `simdata0` | 0 | 512 | DELAY_LEN = 0: pass-through |
| 1 | `simdata1` | 1 | 512 | one cycle |
| 2 | `simdata2` | 5 | 512 | 5 cycles |
| 3 | `simdata3` | 16 | 512 | 16 cycles (counter needs 5 bits) |
| 4 | `simdata4` | 100 | 512 | 100 cycles |
