# sync_delay test data

`sync_delay` delays a sync pulse by `DELAY_LEN` cycles with a loadable down counter (a new pulse restarts the count, so pulses closer than `DELAY_LEN` collapse into the last one). Pulses are mostly spaced `DELAY_LEN`…`2·DELAY_LEN+7` cycles apart, plus 4 at random positions to exercise the restart.

Generated by `test_data/scripts/gen_fft_stage_test_data.py` (Python reference model of `sync_delay_init.m`, not exported from MATLAB). Files: `sim_din.csv`, expected `sim_dout.csv`, one value per cycle.

**CSV data exported from the corresponding MATLAB Simulink block.**

Simulink data: the `sim_*.csv` files of sets 0–4 were exported from Simulink models of the block (MATLAB R2021a, System Generator; plugins-demo2 export flow with its own random stimulus) and copied here on 2026-10-14; `params.json` (and any `.mem` files) are the generator's. Regenerating the module with its script replaces the exported CSVs with the reference model's output.
