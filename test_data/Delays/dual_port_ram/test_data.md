# dual_port_ram test data

`dual_port_ram` is a true dual-port, common-clock RAM (READ_FIRST on each port, 1-cycle registered reads). Both ports read and write at random (50 % writes each); cross-port collisions (same address with a write), which the contract leaves undefined, are removed from the stimulus by moving port B to the next address. Sets with `RST_x` / `EN_x` drive random `sim_rstx.csv` / `sim_enx.csv` as Xilinx `xlDPBRAMXPM.sgm` (latency 1): a disabled port neither reads nor writes and holds its output, `rstx` loads `INIT_X` even on a disabled port, and the outputs show `INIT_A` / `INIT_B` in cycle 0 only, then 0 until the port's first enabled read (checked against Simulink); the other sets leave the options at 0 (not in `params.json`).

Generated by `test_data/scripts/gen_delays_test_data.py` from cycle-accurate Python reference models of the documented behavior (not exported from MATLAB). Each `simdataN/` holds a `params.json` with the DUT parameters (the testbench uses the integer ones to select the data set), input values `sim_we_a.csv`, `sim_addr_a.csv`, `sim_din_a.csv`, `sim_we_b.csv`, `sim_addr_b.csv`, `sim_din_b.csv` and expected output values `sim_dout_a.csv`, `sim_dout_b.csv`, one per clock cycle. Expected outputs follow the pre-edge read convention: the value for cycle i is sampled after clock edge i but reflects the state before it, so the first latency cycles show the zero power-on state.

Only `PLATFORM = "GENERIC"` (the default) is simulated here. The XILINX implementation is checked against GENERIC separately with Vivado xsim (`platform/xilinx/sim/run_xsim_equiv.sh`).

**CSV data exported from the corresponding MATLAB Simulink block.**

Simulink data: the `sim_*.csv` files of sets 0–4 were exported from Simulink models of the block (MATLAB R2021a, System Generator; plugins-demo2 export flow with its own random stimulus) and copied here on 2026-10-14; `params.json` (and any `.mem` files) are the generator's. Regenerating the module with its script replaces the exported CSVs with the reference model's output.
