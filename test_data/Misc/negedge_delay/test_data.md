# negedge_delay test data

`negedge_delay` keeps `dout` high for `PULSE_LEN` cycles after `din` falls, and for the first `PULSE_LEN-1` cycles after power-on. `din` is a level signal with random run lengths shorter and longer than `PULSE_LEN`. The generator also checks `dout(t) = OR(din(t-PULSE_LEN..t)) | (t <= PULSE_LEN-2)`.

Generated by `test_data/scripts/gen_hold_window_test_data.py` from a cycle-level model of the casper_library diagram (not exported from MATLAB). Each `simdataN/` holds `params.json` (the testbench matches it against the DUT parameters) and one `sim_<port>.csv` per port, row i = value driven before / read after clock edge i.

| Test # | Directory | PULSE_LEN | Cycles | Description |
|---|---|---|---|---|
| 0 | `simdata0` | 3 | 500 | Minimum pulse length 3 |
| 1 | `simdata1` | 5 | 500 | Mask default 5; din high from power-on |
| 2 | `simdata2` | 8 | 500 | Pulse length 8 (4-bit counter) |
| 3 | `simdata3` | 16 | 500 | Pulse length 16 (5-bit counter); din high from power-on |
