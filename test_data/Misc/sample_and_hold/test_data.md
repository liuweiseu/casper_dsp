# sample_and_hold test data

`sample_and_hold` registers `din` one cycle after each `sync` and, between syncs, every `PERIOD` cycles. Syncs are sparse with a few back-to-back and closer-than-period ones; `din` is random.

Generated by `test_data/scripts/gen_hold_window_test_data.py` from a cycle-level model of the casper_library diagram (not exported from MATLAB). Each `simdataN/` holds `params.json` (the testbench matches it against the DUT parameters) and one `sim_<port>.csv` per port, row i = value driven before / read after clock edge i.

**CSV data exported from the corresponding MATLAB Simulink block.**

Simulink data: the `sim_*.csv` files of sets 0–3 were exported from Simulink models of the block (MATLAB R2021a, System Generator; plugins-demo2 export flow with its own random stimulus) and copied here on 2026-10-14; `params.json` (and any `.mem` files) are the generator's. Regenerating the module with its script replaces the exported CSVs with the reference model's output.
