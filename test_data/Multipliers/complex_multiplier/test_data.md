# complex_multiplier test data

`complex_multiplier` computes `(a_re + j·a_im)(b_re + j·b_im)` and requantizes both output parts. Tests are paired so that each format is exercised with both `MULT_SPEC`=0 (4-multiply) and `MULT_SPEC`=1 (3-multiply); the expected values of a pair are identical apart from the latency shift. Set 7 also drives random `sim_a_tvalid.csv` / `sim_b_tvalid.csv` (80 % high) and expects `sim_dout_tvalid.csv` = `a_tvalid & b_tvalid` delayed by the latency; the data path ignores the valids (no AXI blocking). The other sets leave both valids at 1.

Generated by `test_data/scripts/gen_fixed_point_test_data.py` from an exact rational-arithmetic golden model (not exported from MATLAB). Each `simdataN/` holds a `params.json` with the DUT parameters (the testbench uses it to select the data set), input words `sim_a_re.csv`, `sim_a_im.csv`, `sim_b_re.csv`, `sim_b_im.csv` and expected output words `sim_dout_re.csv`, `sim_dout_im.csv`. All words are raw unsigned bit patterns, one per clock cycle. Expected outputs already include the pipeline latency (the first `LATENCY` values are the zero power-on state).

The first cycles walk corner-case words (0, 1, all-ones, MSB only, MSB−1, MSB+1; all pairs for 2-input modules), and the rest are seeded uniform-random words.

Encodings: `TYPE` 0=unsigned, 1=signed; `QUANTIZATION` 0=truncate, 1=round half away from zero, 2=round half to even; `OVERFLOW` 0=wrap, 1=saturate.

**CSV data exported from the corresponding MATLAB Simulink block.**

Simulink data: the `sim_*.csv` files of sets 0, 1, 7 were exported from Simulink models of the block (MATLAB R2021a, System Generator; plugins-demo2 export flow with its own random stimulus) and copied here on 2026-10-14; `params.json` (and any `.mem` files) are the generator's. The other sets keep the generated data (sets 2–6: QUANTIZATION 1 / 2 have no Simulink equivalent, the Complex Multiplier 6.0 IP offers only Truncate and Random Rounding). Regenerating the module with its script replaces the exported CSVs with the reference model's output.
