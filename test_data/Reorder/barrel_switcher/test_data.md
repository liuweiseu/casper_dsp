# barrel_switcher test data

`barrel_switcher` rotates its lanes by `sel`: `dout[k] = din[(k + sel) mod N]`, `N_INPUTS` cycles later (`sync_out` likewise). `din`, a new random `sel` every cycle and sparse `sync_in` pulses. The `ASYNC` = 1 set also drives a random `sim_en.csv` and expects `sim_dvalid.csv` = `en` delayed `N_INPUTS` (casper async; the data is not gated).

Generated by `test_data/scripts/gen_reorder_test_data.py` (reference model of `barrel_switcher_init.m`, not exported from MATLAB). CSV rows are cycles; `sim_din<j>.csv` / `sim_dout<j>.csv` hold lane j.

**CSV data exported from the corresponding MATLAB Simulink block.**

Simulink data: the `sim_*.csv` files of sets 0–3 were exported from Simulink models of the block (MATLAB R2021a, System Generator; plugins-demo2 export flow with its own random stimulus) and copied here on 2026-10-14; `params.json` (and any `.mem` files) are the generator's. Regenerating the module with its script replaces the exported CSVs with the reference model's output.
