# cmac test data

`cmac` accumulates `a·conj(b)` over `ACC_LEN` samples and inserts each integration into the `acc_in` relay. Each set has a sync near the start, a whole integration of most-negative inputs (maximum bit growth) and a second, misaligned sync that realigns the integration phase; `acc_in` and `valid_in` are random. The generator checks every dump against the exact sum of `a·conj(b)` over its `ACC_LEN` samples, and every other cycle against the 2-cycle relay of `acc_in` / `valid_in`.

Generated by `test_data/scripts/gen_correlator_test_data.py` from a cycle-level model of the casper_library diagram (not exported from MATLAB). Each `simdataN/` holds `params.json` (the testbench matches it against the DUT parameters) and one `sim_<port>.csv` per port: raw unsigned words in decimal, row i = value driven before / read after clock edge i.
