# xeng_descramble_4ant test data

`xeng_descramble_4ant` is `xeng_descramble` with 4 antennas and a read side of latency 2 (RAM, valid_out, sync_out). Stimulus and checks as for `xeng_descramble`.

Generated by `test_data/scripts/gen_correlator_test_data.py` from a cycle-level model of the casper_library diagram (not exported from MATLAB). Each `simdataN/` holds `params.json` (the testbench matches it against the DUT parameters) and one `sim_<port>.csv` per port: raw unsigned words in decimal, row i = value driven before / read after clock edge i.

| Test # | Directory | N_BITS | ACC_LEN | DEMUX_FACTOR | Cycles | Description |
|---|---|---|---|---|---|---|
| 0 | `simdata0` | 8 | 256 | 1 | 5595 | Mask defaults: W 25 -> P 32, OW 256, DEL 84, CNT 10 |
| 1 | `simdata1` | 4 | 16 | 2 | 382 | 4-bit, ACC_LEN 16, demux 2 |
| 2 | `simdata2` | 8 | 64 | 4 | 1409 | 8-bit, ACC_LEN 64, demux 4 |
