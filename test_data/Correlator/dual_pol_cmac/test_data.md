# dual_pol_cmac test data

`dual_pol_cmac` runs four `cmac`s on the polarisation products `{XX, YY, XY, YX}` = `{a1.p0·conj(a2.p0), a1.p1·conj(a2.p1), a1.p0·conj(a2.p1), a1.p1·conj(a2.p0)}` (p0 in the MSBs of a1/a2; acc_in/acc_out slices in the same order, XX in the MSBs). Only the YX cmac sees `valid_in` and drives `valid_out`. Stimulus and the per-cmac behavioural check are as for `cmac`.

Generated by `test_data/scripts/gen_correlator_test_data.py` from a cycle-level model of the casper_library diagram (not exported from MATLAB). Each `simdataN/` holds `params.json` (the testbench matches it against the DUT parameters) and one `sim_<port>.csv` per port: raw unsigned words in decimal, row i = value driven before / read after clock edge i.
