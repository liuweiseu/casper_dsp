# xeng_descramble test data

`xeng_descramble` writes the X-engine's tap-ordered words to a RAM in element order (conjugating and swapping the last-triangle words) and reads every element out as `DEMUX_FACTOR` narrow words after `start_readout`. Stimulus: sync, three frames of NV valid words. For all but the last set the generator checks every readout against the element table computed from (line, tap) arithmetic (the appendix D map, itself checked against the plan's tables for N = 4, 6, 8), and that reads never hit the wide word being written. Every set shows the spontaneous power-on read pass (D*E valid words, RAM powers up to 0, no sync_out).

Generated by `test_data/scripts/gen_correlator_test_data.py` from a cycle-level model of the casper_library diagram (not exported from MATLAB). Each `simdataN/` holds `params.json` (the testbench matches it against the DUT parameters) and one `sim_<port>.csv` per port: raw unsigned words in decimal, row i = value driven before / read after clock edge i.
