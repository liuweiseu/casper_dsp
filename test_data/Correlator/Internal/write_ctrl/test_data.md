# write_ctrl test data

`write_ctrl` turns the X-engine's tap-ordered words into RAM writes: address (normal region from 0, conjugated last-triangle words from PIVOT, the redundant tap-0 words blanked), write enable, the possibly conjugated data word and start_readout. Stimulus: sync, a window of two frames with NV valid words each (random, some most-negative fields), junk data between valid words. As at the end of the X-engine's tap chain, every antenna line is a burst of T consecutive valid words; after window_valid falls the bursts go on for N/2+1 lines (negedge_delay accepts N/2 of them).

Generated by `test_data/scripts/gen_correlator_test_data.py` from a cycle-level model of the casper_library diagram (not exported from MATLAB). Each `simdataN/` holds `params.json` (the testbench matches it against the DUT parameters) and one `sim_<port>.csv` per port: raw unsigned words in decimal, row i = value driven before / read after clock edge i.
