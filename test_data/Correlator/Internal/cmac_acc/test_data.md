# cmac_acc test data

`cmac_acc` is the accumulate-and-relay cell of `cmac` (`system_871`/`886`): `q <= rst ? din : q + din` (Xilinx Accumulator with hasbypass), `acc_out = rst ? q : acc_in` and `valid_out = rst ? 1 : valid_in`, both delayed 2 cycles.

Generated by `test_data/scripts/gen_correlator_test_data.py` from a cycle-level model of the casper_library diagram (not exported from MATLAB). Each `simdataN/` holds `params.json` (the testbench matches it against the DUT parameters) and one `sim_<port>.csv` per port: raw unsigned words in decimal, row i = value driven before / read after clock edge i.

| Test # | Directory | N_BITS | Cycles | Description |
|---|---|---|---|---|
| 0 | `simdata0` | 16 | 400 | 16-bit, random rst (single, back-to-back, long gaps) |
| 1 | `simdata1` | 6 | 400 | 6-bit: the accumulator wraps |
| 2 | `simdata2` | 1 | 400 | 1-bit |
