# baseline_tap test data

`baseline_tap` delays `a_del` by `ACC_LEN+1` (that is its cmac `a1`) and `a_ndel`, `a_end`, `rst` by 1. A counter reset by `rst` selects the cmac's conjugated input: `a_end` for the first `ANT_SEP*ACC_LEN` samples of each `N_ANTS*ACC_LEN` frame, `a_ndel` afterwards (latency-1 Mux). `sync1` passes straight through. Inputs are random apart from one integration of most-negative samples; there are two rst pulses. Besides these unit sets, the generator chains its auto_tap and baseline_tap models the way xeng does (N_ANTS/ACC_LEN = 4/8, 4/4, 2/8, 3/4, 5/4, 6/4, 8/2) and checks that the loop delay is exactly `N_ANTS*ACC_LEN` and that every integration pairs the same time samples of two antennas of one frame, covering every baseline.

Generated by `test_data/scripts/gen_correlator_test_data.py` from a cycle-level model of the casper_library diagram (not exported from MATLAB). Each `simdataN/` holds `params.json` (the testbench matches it against the DUT parameters) and one `sim_<port>.csv` per port: raw unsigned words in decimal, row i = value driven before / read after clock edge i.
