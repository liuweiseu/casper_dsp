# xeng test data

`xeng` chains auto_tap and N_ANTS/2 baseline_taps, closes the antenna loop, delays window_valid by XENG_DELAY, descrambles the relay stream (xeng_descramble_4ant for 4 antennas) and carries mcnt through three sample_and_holds. Stimulus: sync (after the descramble's power-on read pass), three frames of random antenna data with one most-negative antenna block, a window over those frames, mcnt = cycle/5. The generator asserts that the auto_tap's a_end_out lags `ant` by exactly N_ANTS*ACC_LEN (the testbench checks the same on the RTL), and for the sets marked e2e that every readout is the E dual-polarisation visibilities `[XX, YY, XY, YX] = Σ x·conj(y)` of one complete data frame, one per baseline (x ≤ y), covering every baseline. Set 5 documents the one configuration family found where that does not hold (read pace 1.6 rounded to DEL 0).

Generated by `test_data/scripts/gen_correlator_test_data.py` from a cycle-level model of the casper_library diagram (not exported from MATLAB). Each `simdataN/` holds `params.json` (the testbench matches it against the DUT parameters) and one `sim_<port>.csv` per port: raw unsigned words in decimal, row i = value driven before / read after clock edge i.
