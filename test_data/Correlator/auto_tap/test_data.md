# auto_tap test data

`auto_tap` passes `a_del`, `a_ndel` and `sync_in` (as `rst_out`) straight through, integrates `a_del·conj(a_ndel)` per polarisation product in a `dual_pol_cmac`, delays `a_loop` by `D = (ACC_LEN-1)*ceil(N_ANTS/2) + N_ANTS%2` and `sync_in` by `S = ADD + MULT + ACC_LEN + floor(N_ANTS/2+1) + 1` (`sync_delay`). All inputs are random except one integration of most-negative samples; there are two syncs. The generator also checks the tap chain composition (see `baseline_tap/test_data.md`).

Generated by `test_data/scripts/gen_correlator_test_data.py` from a cycle-level model of the casper_library diagram (not exported from MATLAB). Each `simdataN/` holds `params.json` (the testbench matches it against the DUT parameters) and one `sim_<port>.csv` per port: raw unsigned words in decimal, row i = value driven before / read after clock edge i.
